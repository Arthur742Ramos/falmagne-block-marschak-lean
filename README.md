# Falmagne–Block–Marschak random-utility characterization

A complete, constructive Lean formalization of the finite Falmagne theorem. The alternative type is arbitrary and finite, with no cardinality bound. Every nonempty subset is an observed menu. A normalized nonnegative choice rule has a single probability distribution over complete strict rankings reproducing all menu probabilities if and only if every Block–Marschak alternating-sum coefficient is nonnegative.

## Mathematical statement

For a finite nonempty alternative set X, write p(A,x) for choice probabilities, with p(A,x)=0 outside A and sum over x in A equal to one for every nonempty A. For x in A, define

q(x,A) = sum over B containing A of (-1)^(|B minus A|) p(B,x).

Then q(x,A) >= 0 for every x in A exactly when p is generated by a menu-independent probability distribution on strict linear rankings. Rankings are represented by duplicate-free best-to-worst lists containing every alternative; these lists are precisely strict linear rankings. Their earliest member in a menu is its chosen alternative. The empty-menu probabilities are set to zero as bookkeeping.

The result is the standard strict-ranking, no-ties random-utility characterization. It does not cover unrestricted menu-dependent tie breaking.

## Proof

- Boolean-lattice Möbius inversion identifies q with lower-contour probabilities under any ranking representation
- Normalization gives the Boolean-lattice flow conservation equations
- A genuine constructive flow decomposition extracts a positive complete path, subtracts its smallest edge weight, and inducts on the number of positive edges
- The resulting nonnegative finitely supported ranking law has mass one and reproduces all observed probabilities

There is no flow-decomposition or representation hypothesis in the economic theorem. The proof uses only the three standard classical Lean axioms: propext, Classical.choice, and Quot.sound.

## Files

- Challenge.lean: standalone definitions and exact theorem statement; the single deliberate theorem hole is the Palomar challenge
- Solution.lean: standalone complete solution importing only Mathlib, with no admissions
- EconomicsNextProof/: modular proof development and compiled adversarial examples
- comparator.json and formalization.yaml: Palomar configuration and source-based metadata
- scripts/build_standalone.py: reproducibly generates Challenge/Solution from the development modules
- reports/: local verification records and independent review

The regression examples cover singleton alternatives, empty menus, deterministic four-alternative rankings, a fifty-fifty mixture with zero-probability branches, and a regular normalized stochastic rule whose higher-order Block–Marschak coefficient is negative. The last example formally proves that regularity alone is insufficient. An off-menu negative coefficient also checks the required x-in-A qualification.
